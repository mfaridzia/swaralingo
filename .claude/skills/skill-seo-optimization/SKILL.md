# Skill Procedure: SEO Optimization

1. Pastikan setiap halaman memiliki title dan meta description yang unik.
2. Tambahkan tag OpenGraph: `og:title`, `og:description`, `og:image`, `og:type`.
3. Tambahkan `<link rel="canonical" href="...">`.
4. Sertakan JSON-LD script jika halaman merupakan artikel/produk.
