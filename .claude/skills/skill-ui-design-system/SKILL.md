# Skill Procedure: UI Design System & Aesthetic Styling

Lakukan langkah-langkah berikut saat membuat UI baru:
1. Tentukan CSS Variables HSL di `index.css` untuk Dark/Light mode.
2. Pasang font Google Fonts di HTML `<head>` / Layout.
3. Gunakan komponen Tailwind dengan efek subtle glassmorphism (`backdrop-blur-md bg-white/10 border border-white/20`).
4. Tambahkan mikro-animasi pada button/card (`transition-all duration-300 hover:scale-[1.02] active:scale-[0.98]`).
